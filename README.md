# Задание
После запуска настраивается пользователем:
а) маска входных файлов, например .txt, testFile.bin
b) настройка необходимости удалять входные файлы или нет
c) путь для сохранения результирующих файлов
d) путь для поиска файлов для обработки
e) действия при повторении имени выходного файла: перезапись или
модификация, например, счетчик к имени файла
f) работа по таймеру или разовый запуск
g) периодичность опроса наличия входного файла (таймер)
h) значение 8 байт для бинарной операции модификации файла в формате hex например 1234567890ABCDEF

Функциональность: модифицирует входные файлы, операция XOR с 8-байтной переменной, введенной с формы (Пункт 1,h)

Программа должна позволять обрабатывать файлы большого объёма(10GB) без "замирания" интерфейса! Плюсом будет статус выполнения и прогресс выполнения обработки!
Программа должна иметь возможность приостановить обработку файла в любой момент времени и возобновить её с того же места.
Закрытие программы должно производится корректно даже если в момент закрытие идёт обработка файлов.
